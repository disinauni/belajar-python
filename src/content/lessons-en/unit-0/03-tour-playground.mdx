# Playground Tour

Time to try it out! In this lesson we'll tour the Playground and write our first Python code.

## Playground Anatomy

The Playground consists of:
- **Toolbar** (top) — Run, Reset, Copy, and Download buttons
- **Editor** (left/top) — where you write Python code
- **Output** (right/bottom) — where you see the results

## Your First Code

Try typing this code in the Playground and clicking **Run**:

```python
print("Hello, World!")
```

You'll see the output:
```
Hello, World!
```

Congratulations! You just ran your first Python program! 🎉

## Code Experiments

Now try changing the code to:

```python
print("My name is:", "Alex")
print("I love Python!")
print(2024 + 1)
```

Python can display both text (strings) and numbers directly with `print()`.

## Understanding Errors

Errors are a normal part of programming! Let's intentionally create one:

```python
print("This code has an error"
```

You'll see an error message like:
```
SyntaxError: '(' was never closed
```

This means you forgot to close the parenthesis. Errors help you find where things went wrong.

:::tip
Don't be afraid of errors! They're your friend telling you where the program needs fixing. Read the error message carefully — it's usually quite clear.
:::

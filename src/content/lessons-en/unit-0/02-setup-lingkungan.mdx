# Environment Setup

Good news: **you don't need to install anything** to start learning Python here! This site has a built-in Playground that can run Python code directly in your browser.

But it's good to know your options.

## Option 1: Playground on This Site (Recommended)

The easiest way to start — just use the Playground available in every lesson or on the [Playground](/en/playground) page.

**Advantages:**
- No installation needed
- Ready to use immediately
- Available in every lesson

**Best for:** Learning and completing exercises on this site.

## Option 2: Install Python on Your Computer

If you want to create Python programs that run without internet, you can install Python directly on your computer.

**Steps:**
1. Go to the official Python site at python.org
2. Download the latest Python 3 version (choose the one that matches your OS)
3. Run the installer
4. Check "Add Python to PATH" during installation (important!)
5. After installing, open terminal/command prompt
6. Type `python --version` to verify

## Option 3: Google Colab (Online, Free)

Google Colab is Google's free online Python notebook service, free and no installation needed.

## How to Use the Playground

Each lesson on this site has a built-in **CodePlayground**. Here's how to use it:

1. **Editor Area** (left) — where you write Python code
2. **Output Area** (right) — where the output appears
3. **Run Button** — click to run the code

Try it now with this simple code:

```python
print("Python is ready!")
name = "World"
print("Hello,", name)
```

:::tip
Use the shortcut **Ctrl+Enter** (or Cmd+Enter on Mac) to run code faster without clicking the Run button.
:::

## Python Version

There are two major Python versions: **Python 2** and **Python 3**. Python 2 has been discontinued since 2020. All material on this site uses **Python 3** — make sure you use the same version!

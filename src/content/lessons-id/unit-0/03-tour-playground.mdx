# Tour Playground

Saatnya mencoba langsung! Di pelajaran ini kita akan keliling Playground dan menulis kode Python pertama.

## Anatomi Playground

Playground terdiri dari beberapa bagian:

- **Toolbar** (atas) — tombol Run, Reset, Copy, dan Download
- **Editor** (kiri/atas) — tempat menulis kode Python
- **Output** (kanan/bawah) — tempat melihat hasil kode

## Kode Pertamamu

Coba ketik kode ini di Playground dan klik **Run**:

```python
print("Halo, Dunia!")
```

Kamu akan melihat output:
```
Halo, Dunia!
```

Selamat! Kamu baru saja menjalankan program Python pertamamu! 🎉

## Eksperimen Kode

Sekarang coba ubah kode menjadi ini:

```python
print("Nama saya:", "Budi")
print("Saya suka Python!")
print(2024 + 1)
```

Output yang diharapkan:
```
Nama saya: Budi
Saya suka Python!
2025
```

Python bisa menampilkan teks (string) maupun angka langsung dengan `print()`.

## Memahami Error

Error adalah bagian normal dari programming — semua programmer pernah mengalaminya! Mari coba membuat error dengan sengaja:

```python
print("Ini kode yang salah"
```

Kamu akan melihat pesan error seperti:
```
SyntaxError: '(' was never closed
```

Ini berarti kamu lupa menutup tanda kurung. Error membantumu menemukan di mana letak kesalahan.

:::tip
Jangan takut dengan error! Error adalah teman yang memberitahumu di mana program perlu diperbaiki. Baca pesan error dengan teliti — biasanya cukup jelas.
:::

## Tombol-Tombol Penting

| Tombol | Fungsi |
|--------|--------|
| **Run** | Jalankan kode |
| **Reset** | Kembalikan kode ke semula |
| **Copy** | Salin semua kode |
| **Download** | Unduh kode sebagai file `.py` |

# Apa itu Python?

Sebelum mulai menulis kode, mari kenali dulu bahasa yang akan kita pelajari: **Python**.

## Python adalah Bahasa Pemrograman

Python adalah bahasa pemrograman — sebuah cara untuk memberikan instruksi kepada komputer. Bayangkan komputer seperti robot yang sangat patuh: dia akan melakukan **apapun** yang kamu perintahkan, tapi kamu harus berbicara dengan bahasa yang dia mengerti.

Python adalah salah satu "bahasa" yang dimengerti komputer.

## Sejarah Singkat

Python dibuat oleh **Guido van Rossum**, seorang programmer asal Belanda. Dia mulai mengembangkan Python pada akhir 1980-an dan merilis versi pertamanya pada 1991. Nama "Python" bukan dari ular — Guido mengambilnya dari serial komedi favoritnya, **Monty Python's Flying Circus**!

Saat ini Python sudah di versi 3.x dan menjadi salah satu bahasa pemrograman paling populer di dunia.

## Python Digunakan untuk Apa?

Python sangat serbaguna. Di dunia nyata, Python digunakan untuk:

**🤖 Kecerdasan Buatan & Machine Learning**
- ChatGPT, Stable Diffusion, dan banyak AI dibuat dengan Python
- Library seperti TensorFlow dan PyTorch

**🌐 Web Development**
- Instagram, YouTube, dan Spotify menggunakan Python di backend mereka
- Framework seperti Django dan Flask

**📊 Analisis Data & Ilmu Data**
- Ilmuwan dan analis data menggunakan Python untuk mengolah jutaan data
- Library seperti Pandas, NumPy, Matplotlib

**🎮 Game & Otomasi**
- Otomasi tugas berulang di komputer
- Membuat skrip untuk menghemat waktu

**🔬 Sains & Riset**
- NASA dan CERN menggunakan Python untuk riset mereka

## Mengapa Python Cocok untuk Pemula?

Ada banyak bahasa pemrograman di dunia, tapi Python punya keunggulan khusus untuk pemula:

### 1. Sintaks yang Bersih dan Mudah Dibaca

Bandingkan program "Hello, World!" di beberapa bahasa:

**Java:**
```
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

**Python:**
```python
print("Hello, World!")
```

Python jauh lebih ringkas dan mudah dibaca — hampir seperti bahasa Inggris biasa!

### 2. Tidak Perlu Kompilasi

Bahasa seperti C++ perlu "dikompilasi" (diterjemahkan ke bahasa mesin) sebelum bisa dijalankan. Python langsung **diinterpretasi** — tulis kode, langsung jalan!

### 3. Komunitas yang Besar

Ada jutaan programmer Python di seluruh dunia. Kalau kamu stuck, pasti ada yang bisa membantu. Ada juga ribuan library gratis yang bisa kamu gunakan.

### 4. Prospek Karir yang Bagus

Python adalah salah satu skill yang paling dicari perusahaan teknologi. Mempelajarinya membuka pintu ke banyak karir: data scientist, AI engineer, web developer, dan lainnya.

## Python di Kehidupan Sehari-hari

Tanpa kamu sadari, Python sudah banyak mempengaruhi hidupmu:

- Rekomendasi video YouTube yang kamu tonton
- Filter foto di Instagram
- Iklan yang muncul di media sosial
- Prediksi cuaca di aplikasi cuaca
- Sistem pendeteksi spam di email

Semua itu ditenagai Python (atau teknologi yang dibangun dengan Python)!

:::note
**Python vs Python (ular)**: Jangan bingung! Python bahasa pemrograman tidak ada hubungannya dengan ular python. Logo Python memang bergambar ular, tapi itu hanya karena namanya kebetulan sama.
:::

# Setup Lingkungan

Kabar baik: **kamu tidak perlu menginstall apapun** untuk mulai belajar Python di sini! Situs ini punya Playground bawaan yang bisa menjalankan kode Python langsung di browser.

Tapi ada baiknya kamu tahu opsi-opsi yang tersedia.

## Opsi 1: Playground di Situs Ini (Direkomendasikan)

Cara paling mudah untuk mulai — langsung gunakan Playground yang ada di setiap pelajaran atau di halaman [Playground](/id/playground).

**Kelebihan:**
- Tidak perlu install apapun
- Langsung bisa dipakai
- Tersedia di setiap pelajaran

**Cocok untuk:** Belajar dan mengerjakan latihan di situs ini.

## Opsi 2: Install Python di Komputer

Kalau kamu ingin membuat program Python yang bisa dijalankan tanpa internet, kamu bisa install Python langsung di komputermu.

**Langkah-langkah:**
1. Buka situs resmi Python di python.org
2. Download versi terbaru Python 3 (pastikan pilih yang sesuai OS kamu)
3. Jalankan installer
4. Centang opsi "Add Python to PATH" saat instalasi (penting!)
5. Setelah selesai, buka terminal/command prompt
6. Ketik `python --version` untuk verifikasi

**Kelebihan:**
- Bisa membuat program yang berjalan offline
- Bisa install library tambahan (Pandas, NumPy, dll)
- Pengalaman yang lebih "nyata"

## Opsi 3: Google Colab (Online, Gratis)

Google Colab adalah layanan notebook Python online dari Google, gratis dan tidak butuh install.

**Kelebihan:**
- Cocok untuk data science dan ML
- Punya GPU gratis untuk komputasi berat
- Bisa share notebook dengan orang lain

## Cara Menggunakan Playground

Setiap pelajaran di situs ini punya **CodePlayground** bawaan. Berikut cara menggunakannya:

1. **Area Editor** (kiri) — tempat kamu menulis kode Python
2. **Area Output** (kanan) — tempat output kodenya muncul
3. **Tombol Run** — klik untuk menjalankan kode

Coba sekarang dengan kode sederhana ini:

```python
print("Python siap digunakan!")
nama = "Budi"
print("Halo,", nama)
```

:::tip
Gunakan shortcut **Ctrl+Enter** (atau Cmd+Enter di Mac) untuk menjalankan kode lebih cepat tanpa harus klik tombol Run.
:::

## Tentang Versi Python

Ada dua versi utama Python: **Python 2** dan **Python 3**. Python 2 sudah tidak dikembangkan lagi sejak 2020. Semua materi di situs ini menggunakan **Python 3** — pastikan kamu pakai versi yang sama!

Cara cek versi Python di komputer:
```
python --version
```
atau
```
python3 --version
```

## Python REPL

Kalau kamu sudah install Python, coba ini: buka terminal dan ketik `python` (atau `python3`). Kamu akan masuk ke **REPL** (Read-Eval-Print Loop) — sebuah mode interaktif di mana kamu bisa langsung ketik kode dan lihat hasilnya.

```
>>> print("Halo!")
Halo!
>>> 2 + 3
5
>>> nama = "Budi"
>>> print(f"Halo, {nama}!")
Halo, Budi!
```

REPL bagus untuk eksperimen cepat. Tapi untuk program yang lebih panjang, lebih baik tulis di file `.py`.

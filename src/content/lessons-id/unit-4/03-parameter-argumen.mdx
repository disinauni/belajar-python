# Parameter & Argumen

## Parameter vs Argumen

- **Parameter** — variabel dalam definisi fungsi (placeholder)
- **Argumen** — nilai aktual yang dikirim saat memanggil fungsi

```python
def sapa(nama):      # 'nama' adalah PARAMETER
    print(f"Halo, {nama}!")

sapa("Budi")         # "Budi" adalah ARGUMEN
sapa("Siti")
sapa("Andi")
```

## Banyak Parameter

```python
def perkenalan(nama, umur, kota):
    print(f"Halo! Nama saya {nama}.")
    print(f"Saya berumur {umur} tahun dari {kota}.")

perkenalan("Budi", 17, "Jakarta")
perkenalan("Siti", 16, "Bandung")
```

## Contoh Fungsi dengan Kalkulasi

```python
def hitung_luas_segitiga(alas, tinggi):
    luas = 0.5 * alas * tinggi
    print(f"Luas segitiga (alas={alas}, tinggi={tinggi}) = {luas}")

def hitung_keliling_persegi_panjang(panjang, lebar):
    keliling = 2 * (panjang + lebar)
    print(f"Keliling persegi panjang = {keliling}")

hitung_luas_segitiga(6, 4)
hitung_keliling_persegi_panjang(10, 5)
```

## Urutan Argumen Penting

```python
def bagi(pembilang, penyebut):
    print(f"{pembilang} / {penyebut} = {pembilang / penyebut}")

bagi(10, 2)   # 10 / 2 = 5.0
bagi(2, 10)   # 2 / 10 = 0.2 (urutan berbeda, hasil berbeda!)
```

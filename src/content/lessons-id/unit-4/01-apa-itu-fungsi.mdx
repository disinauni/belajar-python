# Apa itu Fungsi?

Bayangkan kamu harus menulis kode yang sama di 10 tempat berbeda. Sangat merepotkan! Fungsi memungkinkan kamu menulis kode sekali dan menggunakannya berkali-kali.

## Mengapa Fungsi?

```python
# Tanpa fungsi — repetitif dan susah dirawat
print("=" * 30)
print("LAPORAN NILAI SISWA")
print("=" * 30)

# ... (kode lain) ...

print("=" * 30)
print("LAPORAN KEHADIRAN")
print("=" * 30)

# Dengan fungsi — tulis sekali, panggil berkali-kali
def cetak_header(judul):
    print("=" * 30)
    print(judul)
    print("=" * 30)

cetak_header("LAPORAN NILAI SISWA")
cetak_header("LAPORAN KEHADIRAN")
```

## Fungsi Built-in Python

Kamu sudah sering pakai fungsi bawaan Python:

```python
print(len("Hello"))    # len() — hitung panjang
print(abs(-5))         # abs() — nilai absolut
print(max(3, 7, 1))    # max() — nilai terbesar
print(min(3, 7, 1))    # min() — nilai terkecil
print(sum([1,2,3,4]))  # sum() — jumlah
print(round(3.7))      # round() — pembulatan
print(type(42))        # type() — tipe data
```

Semua ini adalah **fungsi** — blok kode yang sudah ditulis seseorang dan bisa kamu gunakan.

## Keuntungan Menggunakan Fungsi

1. **DRY** (Don't Repeat Yourself) — tulis sekali, pakai berkali-kali
2. **Mudah dibaca** — nama fungsi menjelaskan apa yang dilakukannya
3. **Mudah ditest** — bisa tes fungsi satu per satu
4. **Mudah diubah** — ubah di satu tempat, berpengaruh di semua tempat

Di pelajaran berikutnya kita akan belajar cara membuat fungsi sendiri!

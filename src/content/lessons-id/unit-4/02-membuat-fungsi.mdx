# Membuat Fungsi

## Sintaks Membuat Fungsi

```python
def nama_fungsi():
    # isi fungsi (body)
    # diindentasi 4 spasi
```

## Contoh Pertama

```python
def sapa():
    print("Halo!")
    print("Selamat datang di Python!")

# Definisi di atas TIDAK menjalankan kode — hanya mendefinisikan
# Untuk menjalankan, kamu harus MEMANGGIL fungsinya:

sapa()   # panggil sekali
sapa()   # panggil lagi
sapa()   # dan lagi
```

Output:
```
Halo!
Selamat datang di Python!
Halo!
Selamat datang di Python!
Halo!
Selamat datang di Python!
```

## Fungsi Harus Didefinisikan Dulu

```python
# SALAH — fungsi dipanggil sebelum didefinisikan
# sapa()  # NameError!

# def sapa():
#     print("Halo")

# BENAR — definisi dulu, baru panggil
def sapa():
    print("Halo")

sapa()  # sekarang bisa
```

## Contoh Program

```python
def tampilkan_menu():
    print("\n=== MENU UTAMA ===")
    print("1. Lihat profil")
    print("2. Tambah nilai")
    print("3. Keluar")
    print("=" * 18)

def tampilkan_profil():
    print("\n--- Profil ---")
    print("Nama: Budi Santoso")
    print("Kelas: X IPA 2")
    print("Sekolah: SMA N 1 Jakarta")

# Program utama
tampilkan_menu()
pilihan = input("Pilih menu: ")

if pilihan == "1":
    tampilkan_profil()
elif pilihan == "3":
    print("Sampai jumpa!")
```

## Konvensi Nama Fungsi

```python
def hitung_luas_persegi(sisi):   # bagus
def HitungLuasPersegi(sisi):     # kurang Python-ic (ini untuk class)
def hitungluas(sisi):            # susah dibaca
```

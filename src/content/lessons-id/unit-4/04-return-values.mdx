# Return Values

Fungsi tidak hanya bisa menampilkan sesuatu — ia juga bisa **mengembalikan nilai** yang bisa digunakan oleh kode lain.

## Perbedaan print vs return

```python
# Fungsi dengan print — hanya tampilkan, tidak bisa digunakan lagi
def tambah_print(a, b):
    print(a + b)

hasil = tambah_print(5, 3)  # menampilkan 8
print(hasil)  # None! fungsi tidak mengembalikan apa-apa

# Fungsi dengan return — mengembalikan nilai
def tambah_return(a, b):
    return a + b

hasil = tambah_return(5, 3)  # simpan nilai kembalian
print(hasil)  # 8
print(hasil * 2)  # 16 — bisa digunakan!
```

## Contoh Return

```python
def luas_lingkaran(r):
    return 3.14159 * r ** 2

def keliling_lingkaran(r):
    return 2 * 3.14159 * r

r = 7
print(f"Luas: {luas_lingkaran(r):.2f}")
print(f"Keliling: {keliling_lingkaran(r):.2f}")

# Bisa langsung dipakai dalam ekspresi
total_luas = luas_lingkaran(5) + luas_lingkaran(3)
print(f"Total luas: {total_luas:.2f}")
```

## Return Banyak Nilai

Python bisa mengembalikan beberapa nilai sekaligus (sebagai tuple):

```python
def statistik(data):
    total = sum(data)
    rata = total / len(data)
    terbesar = max(data)
    terkecil = min(data)
    return rata, terbesar, terkecil  # return 3 nilai

nilai = [85, 92, 78, 88, 65, 90]
rata2, max_val, min_val = statistik(nilai)  # unpacking

print(f"Rata-rata: {rata2:.1f}")
print(f"Nilai tertinggi: {max_val}")
print(f"Nilai terendah: {min_val}")
```

## Early Return

```python
def bagi_aman(a, b):
    if b == 0:
        return None  # return lebih awal untuk kasus error
    return a / b

print(bagi_aman(10, 2))   # 5.0
print(bagi_aman(10, 0))   # None
```

# Input & Output

Program yang menarik adalah program yang bisa **berinteraksi** dengan pengguna — menerima masukan dan memberikan output yang relevan. Python menyediakan `input()` untuk ini.

## Fungsi `input()`

`input()` menghentikan program dan menunggu pengguna mengetik sesuatu, lalu menekan Enter:

```python
nama = input("Masukkan namamu: ")
print("Halo,", nama)
```

Saat dijalankan:
```
Masukkan namamu: Budi
Halo, Budi
```

### Cara Kerja `input()`

1. Python menampilkan teks prompt (opsional)
2. Program berhenti, menunggu pengguna mengetik
3. Pengguna tekan Enter
4. Apa yang diketik disimpan sebagai **string**

:::warning
`input()` **selalu mengembalikan string** — bahkan jika pengguna mengetik angka! Ini penting dan sering jadi sumber bug bagi pemula.
:::

## Konversi Tipe Input

Karena `input()` selalu mengembalikan string, kamu perlu **mengkonversi** ke tipe yang dibutuhkan:

```python
# Salah — ini string, bukan integer!
usia_str = input("Masukkan usia: ")
# usia_str + 1  <-- ERROR! tidak bisa tambah string dengan angka

# Benar — konversi ke integer dulu
usia = int(input("Masukkan usia: "))
tahun_lahir = 2024 - usia
print("Kamu lahir tahun:", tahun_lahir)
```

### Fungsi Konversi Tipe

| Fungsi | Kegunaan | Contoh |
|--------|----------|--------|
| `int()` | String → Integer | `int("42")` → `42` |
| `float()` | String → Float | `float("3.14")` → `3.14` |
| `str()` | Angka → String | `str(42)` → `"42"` |
| `bool()` | → Boolean | `bool(1)` → `True` |

```python
umur = int(input("Umur: "))
tinggi = float(input("Tinggi (cm): "))
nama = input("Nama: ")

print("Nama:", nama)
print("Umur:", umur, "tahun")
print("Tinggi:", tinggi, "cm")
```

## F-String — Format Output Modern

**F-string** (formatted string literal) adalah cara paling elegan untuk memformat output di Python:

```python
nama = "Budi"
umur = 17
nilai = 87.5

# Cara lama (concatenation)
print("Nama: " + nama + ", umur: " + str(umur))

# Cara f-string (lebih rapi!)
print(f"Nama: {nama}, umur: {umur}")
print(f"Nilai rata-rata: {nilai:.2f}")  # 2 angka desimal
```

Output:
```
Nama: Budi, umur: 17
Nilai rata-rata: 87.50
```

### Kelebihan F-String

1. **Lebih mudah dibaca** — tidak perlu banyak tanda `+` atau `str()`
2. **Bisa ekspresi** — bisa langsung hitung di dalam kurung kurawal
3. **Format angka** — bisa atur jumlah desimal, padding, dll

```python
a = 10
b = 3

print(f"{a} + {b} = {a + b}")
print(f"{a} / {b} = {a / b:.3f}")  # 3 angka desimal
print(f"Pi ≈ {3.14159:.2f}")

nama = "budi"
print(f"Halo, {nama.upper()}!")  # bisa panggil method di dalam f-string
```

Output:
```
10 + 3 = 13
10 / 3 = 3.333
Pi ≈ 3.14
Halo, BUDI!
```

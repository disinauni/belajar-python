# Project: Kalkulator Sederhana

Saatnya menggabungkan semua yang sudah kamu pelajari di Unit 1 untuk membuat **kalkulator sederhana** yang bisa melakukan operasi matematika dasar!

## Spesifikasi Program

Kalkulator yang akan kita buat:
1. Meminta dua angka dari pengguna
2. Meminta operasi yang diinginkan (+, -, *, /)
3. Menghitung dan menampilkan hasilnya
4. Menampilkan dengan format yang rapi

## Versi 1: Kalkulator Sederhana

```python
# Kalkulator Sederhana v1.0
# Dibuat dengan Python dasar

print("╔══════════════════════╗")
print("║   KALKULATOR PYTHON  ║")
print("╚══════════════════════╝")
print()

# Input dari pengguna
angka1 = float(input("Masukkan angka pertama : "))
angka2 = float(input("Masukkan angka kedua   : "))

# Hitung semua operasi
jumlah = angka1 + angka2
selisih = angka1 - angka2
kali = angka1 * angka2

# Tampilkan hasil
print()
print("══════════════════════════")
print(f"  {angka1} + {angka2} = {jumlah}")
print(f"  {angka1} - {angka2} = {selisih}")
print(f"  {angka1} × {angka2} = {kali}")

if angka2 != 0:
    bagi = angka1 / angka2
    print(f"  {angka1} ÷ {angka2} = {bagi:.4f}")
else:
    print("  Pembagian: tidak bisa dibagi nol!")

print("══════════════════════════")
```

## Versi 2: Kalkulator Interaktif

Versi yang lebih canggih — pengguna memilih operasinya:

```python
# Kalkulator Interaktif v2.0

print("=== Kalkulator Python ===\n")

angka1 = float(input("Angka pertama : "))
angka2 = float(input("Angka kedua   : "))

print("\nPilih operasi:")
print("1. Penjumlahan (+)")
print("2. Pengurangan (-)")
print("3. Perkalian (×)")
print("4. Pembagian (÷)")
print("5. Pangkat (^)")
print("6. Sisa bagi (%)")

pilihan = input("\nPilihan (1-6): ")

print()
if pilihan == "1":
    hasil = angka1 + angka2
    print(f"Hasil: {angka1} + {angka2} = {hasil}")

elif pilihan == "2":
    hasil = angka1 - angka2
    print(f"Hasil: {angka1} - {angka2} = {hasil}")

elif pilihan == "3":
    hasil = angka1 * angka2
    print(f"Hasil: {angka1} × {angka2} = {hasil}")

elif pilihan == "4":
    if angka2 != 0:
        hasil = angka1 / angka2
        print(f"Hasil: {angka1} ÷ {angka2} = {hasil:.6f}")
    else:
        print("Error: Tidak bisa membagi dengan nol!")

elif pilihan == "5":
    hasil = angka1 ** angka2
    print(f"Hasil: {angka1} ^ {angka2} = {hasil}")

elif pilihan == "6":
    if angka2 != 0:
        hasil = angka1 % angka2
        print(f"Hasil: {angka1} % {angka2} = {hasil}")
    else:
        print("Error: Tidak bisa modulo dengan nol!")

else:
    print("Pilihan tidak valid!")
```

## Versi 3: Kalkulator dengan Fitur Tambahan

Tambahkan fitur konversi suhu dan luas:

```python
# Kalkulator Lengkap v3.0

print("╔═══════════════════════════╗")
print("║   KALKULATOR PYTHON 3.0   ║")
print("╚═══════════════════════════╝\n")

print("Menu:")
print("1. Kalkulator Dasar")
print("2. Konversi Suhu")
print("3. Hitung Luas Bangun Datar")

menu = input("\nPilih menu (1-3): ")
print()

if menu == "1":
    a = float(input("Angka 1: "))
    b = float(input("Angka 2: "))
    print(f"\n{a} + {b} = {a+b}")
    print(f"{a} - {b} = {a-b}")
    print(f"{a} × {b} = {a*b}")
    if b != 0:
        print(f"{a} ÷ {b} = {a/b:.4f}")

elif menu == "2":
    suhu = float(input("Suhu Celsius: "))
    fahrenheit = (suhu * 9/5) + 32
    kelvin = suhu + 273.15
    print(f"\n{suhu}°C = {fahrenheit:.2f}°F")
    print(f"{suhu}°C = {kelvin:.2f}K")

elif menu == "3":
    print("Pilih bangun:")
    print("a. Persegi panjang")
    print("b. Lingkaran")
    print("c. Segitiga")
    bangun = input("Pilihan: ").lower()

    if bangun == "a":
        p = float(input("Panjang: "))
        l = float(input("Lebar: "))
        luas = p * l
        keliling = 2 * (p + l)
        print(f"\nLuas: {luas}")
        print(f"Keliling: {keliling}")

    elif bangun == "b":
        r = float(input("Jari-jari: "))
        pi = 3.14159
        luas = pi * r ** 2
        keliling = 2 * pi * r
        print(f"\nLuas: {luas:.2f}")
        print(f"Keliling: {keliling:.2f}")

    elif bangun == "c":
        alas = float(input("Alas: "))
        tinggi = float(input("Tinggi: "))
        luas = 0.5 * alas * tinggi
        print(f"\nLuas: {luas}")

else:
    print("Menu tidak valid!")

print("\nTerima kasih telah menggunakan Kalkulator Python!")
```

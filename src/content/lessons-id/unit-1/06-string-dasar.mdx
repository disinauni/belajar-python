# String Dasar

String adalah tipe data yang sangat sering digunakan. Python punya banyak fitur built-in untuk memanipulasi string.

## String adalah Urutan Karakter

Setiap karakter dalam string punya **indeks** (posisi), dimulai dari 0:

```python
kata = "Python"
#       P y t h o n
# indeks 0 1 2 3 4 5

print(kata[0])   # P
print(kata[1])   # y
print(kata[5])   # n
print(kata[-1])  # n (indeks negatif dari belakang)
print(kata[-2])  # o
```

:::note
Python menggunakan **zero-based indexing** — indeks pertama adalah 0, bukan 1. Ini standar di hampir semua bahasa pemrograman modern.
:::

## Slicing — Memotong String

Slicing mengambil bagian dari string:

```python
kata = "Python"

print(kata[0:3])  # Pyt (indeks 0, 1, 2 — tidak termasuk 3)
print(kata[2:5])  # tho
print(kata[:3])   # Pyt (dari awal sampai indeks 3)
print(kata[3:])   # hon (dari indeks 3 sampai akhir)
print(kata[:])    # Python (seluruh string)
print(kata[::2])  # Pto (setiap 2 karakter)
print(kata[::-1]) # nohtyP (dibalik!)
```

**Format slicing:** `string[start:stop:step]`

## Panjang String dengan `len()`

```python
kalimat = "Saya belajar Python"
print(len(kalimat))  # 19

nama = ""
print(len(nama))  # 0 (string kosong)
```

## Method String yang Penting

String punya banyak **method** (fungsi bawaan) yang berguna:

```python
teks = "  Hello, World!  "

# Mengubah case
print(teks.upper())     # "  HELLO, WORLD!  "
print(teks.lower())     # "  hello, world!  "
print(teks.title())     # "  Hello, World!  "
print(teks.capitalize())  # "  hello, world!  " (hanya huruf pertama)

# Menghapus spasi
print(teks.strip())     # "Hello, World!" (hapus spasi depan-belakang)
print(teks.lstrip())    # "Hello, World!  " (hapus kiri)
print(teks.rstrip())    # "  Hello, World!" (hapus kanan)

# Mencari
print(teks.find("World"))   # 9 (indeks pertama ditemukan)
print(teks.count("l"))      # 3 (berapa kali muncul)
print("World" in teks)      # True (cek keberadaan)

# Mengganti
print(teks.replace("World", "Python"))  # "  Hello, Python!  "

# Memisahkan
kalimat = "apel,mangga,jeruk"
print(kalimat.split(","))  # ['apel', 'mangga', 'jeruk']

# Bergabung
buah = ["apel", "mangga", "jeruk"]
print(", ".join(buah))  # "apel, mangga, jeruk"

# Cek isi
angka = "12345"
print(angka.isdigit())   # True (semua angka)
print("abc".isalpha())   # True (semua huruf)
print("abc123".isalnum()) # True (huruf dan angka)
```

## F-String Lanjutan

F-string sangat powerful untuk memformat output:

```python
nama = "Budi"
nilai = 87.6789
peringkat = 3

# Format angka desimal
print(f"Nilai: {nilai:.2f}")     # Nilai: 87.68
print(f"Nilai: {nilai:.0f}")     # Nilai: 88

# Padding dan alignment
print(f"|{'Kiri':<10}|")        # |Kiri      | (rata kiri, lebar 10)
print(f"|{'Kanan':>10}|")       # |     Kanan| (rata kanan)
print(f"|{'Tengah':^10}|")      # |  Tengah  | (rata tengah)

# Format angka dengan separator ribuan
angka_besar = 1000000
print(f"Rp {angka_besar:,}")    # Rp 1,000,000
print(f"Rp {angka_besar:_.0f}") # Rp 1_000_000

# Ekspresi di dalam f-string
print(f"10 + 20 = {10 + 20}")
print(f"{nama.upper()} berada di peringkat {peringkat}")
```

## Contoh Program Lengkap

```python
# Analisis nama
nama = input("Masukkan namamu: ")

print(f"\nAnalisis nama '{nama}':")
print(f"Jumlah karakter: {len(nama)}")
print(f"Huruf kapital semua: {nama.upper()}")
print(f"Huruf kecil semua: {nama.lower()}")
print(f"Title case: {nama.title()}")
print(f"Karakter pertama: {nama[0]}")
print(f"Karakter terakhir: {nama[-1]}")
print(f"Dibalik: {nama[::-1]}")
```

## Ringkasan

| Operasi | Sintaks | Contoh |
|---------|---------|--------|
| Akses karakter | `s[i]` | `"Python"[0]` → `P` |
| Slicing | `s[a:b]` | `"Python"[1:4]` → `yth` |
| Panjang | `len(s)` | `len("Hello")` → `5` |
| Uppercase | `s.upper()` | `"hello".upper()` → `HELLO` |
| Strip spasi | `s.strip()` | `"  hi  ".strip()` → `hi` |
| Ganti | `s.replace(a,b)` | `"hello".replace("l","r")` → `herro` |
| Pisah | `s.split(sep)` | `"a,b".split(",")` → `['a','b']` |

Di pelajaran berikutnya: **Konversi Tipe Data** — mengubah data dari satu tipe ke tipe lain!

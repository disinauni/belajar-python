# Operasi Aritmatika

Python bisa digunakan sebagai kalkulator yang sangat powerful. Mari pelajari semua operator aritmatika yang tersedia.

## Operator Dasar

```python
a = 10
b = 3

print(f"{a} + {b} = {a + b}")   # 13
print(f"{a} - {b} = {a - b}")   # 7
print(f"{a} * {b} = {a * b}")   # 30
print(f"{a} / {b} = {a / b}")   # 3.3333...
print(f"{a} // {b} = {a // b}") # 3 (floor division)
print(f"{a} % {b} = {a % b}")   # 1 (modulo/sisa bagi)
print(f"{a} ** {b} = {a ** b}") # 1000 (pemangkatan)
```

## Pembagian: `/` vs `//`

Ini perbedaan penting yang sering membingungkan:

```python
print(10 / 3)   # 3.3333333333333335 — hasil float
print(10 // 3)  # 3 — hanya bagian bulatnya
print(7 / 2)    # 3.5 — hasil float
print(7 // 2)   # 3 — floor division
```

- `/` (division) — selalu menghasilkan **float**
- `//` (floor division) — membulatkan **ke bawah**, hasilnya int

```python
# Contoh: pembagian jam dan menit
total_menit = 150
jam = total_menit // 60    # 2 jam
menit = total_menit % 60   # 30 menit
print(f"{total_menit} menit = {jam} jam {menit} menit")
# Output: 150 menit = 2 jam 30 menit
```

## Modulo `%` — Sangat Berguna!

Modulo (%) memberikan **sisa pembagian**:

```python
print(10 % 3)  # 1 (10 = 3*3 + 1)
print(15 % 5)  # 0 (15 habis dibagi 5)
print(7 % 2)   # 1 (bilangan ganjil)
print(8 % 2)   # 0 (bilangan genap)
```

**Trik umum dengan modulo:**
```python
# Cek apakah angka genap atau ganjil
angka = 17
if angka % 2 == 0:
    print("Genap")
else:
    print("Ganjil")
```

## Pemangkatan `**`

```python
print(2 ** 3)    # 8 (2 pangkat 3)
print(3 ** 2)    # 9 (3 kuadrat)
print(16 ** 0.5) # 4.0 (akar kuadrat = pangkat 0.5)
print(2 ** 10)   # 1024
```

:::tip
Untuk akar kuadrat, kamu bisa gunakan `** 0.5` atau import modul math: `import math; math.sqrt(16)`.
:::

## Urutan Operasi (PEMDAS)

Python mengikuti urutan operasi matematika standar:

```python
# Urutan: Parentheses, Exponents, Multiply/Divide, Add/Subtract
print(2 + 3 * 4)      # 14 (bukan 20!) — perkalian dulu
print((2 + 3) * 4)    # 20 — kurung dulu
print(2 ** 3 ** 2)    # 512 (2^(3^2) = 2^9) — pangkat dari kanan
print(10 - 3 - 2)     # 5 — kiri ke kanan
```

## Operator Assignment Gabungan

Python punya shortcut untuk operasi umum:

```python
skor = 100

skor += 10   # sama dengan: skor = skor + 10
print(skor)  # 110

skor -= 5    # sama dengan: skor = skor - 5
print(skor)  # 105

skor *= 2    # sama dengan: skor = skor * 2
print(skor)  # 210

skor //= 3   # sama dengan: skor = skor // 3
print(skor)  # 70

skor %= 50   # sama dengan: skor = skor % 50
print(skor)  # 20

skor **= 2   # sama dengan: skor = skor ** 2
print(skor)  # 400
```

## Operasi Campuran Int dan Float

```python
print(5 + 2.0)    # 7.0 (int + float = float)
print(10 / 2)     # 5.0 (selalu float)
print(10 // 2)    # 5 (int)
print(type(5 + 2))    # <class 'int'>
print(type(5 + 2.0))  # <class 'float'>
```

**Aturan:** Jika ada float dalam operasi, hasilnya float.

## Contoh Program: Kalkulator Sederhana

```python
print("=== Kalkulator Sederhana ===")
a = float(input("Angka pertama: "))
b = float(input("Angka kedua: "))

print(f"\n{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} × {b} = {a * b}")
if b != 0:
    print(f"{a} ÷ {b} = {a / b:.4f}")
else:
    print("Tidak bisa dibagi nol!")
```

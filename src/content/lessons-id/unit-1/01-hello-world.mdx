# Hello, World!

Ada tradisi di dunia programming: program pertama yang kamu tulis dalam bahasa baru haruslah program yang menampilkan "Hello, World!" di layar. Tradisi ini dimulai dari buku legenda "The C Programming Language" tahun 1978. Sekarang giliranmu melanjutkan tradisi ini — dalam Python!

## Program Pertamamu

Berikut program Hello World dalam Python:

```python
print("Hello, World!")
```

Ketik kode ini di playground, lalu klik **Run**. Kamu akan melihat:

```
Hello, World!
```

Selamat! Hanya satu baris, tapi itu sudah program yang valid!

## Memahami `print()`

`print()` adalah **fungsi** bawaan Python yang tugasnya menampilkan sesuatu ke layar. 

```python
print("Halo, Dunia!")
print("Nama saya Budi.")
print("Saya sedang belajar Python!")
```

Output:
```
Halo, Dunia!
Nama saya Budi.
Saya sedang belajar Python!
```

Setiap pemanggilan `print()` otomatis pindah ke baris baru.

## Anatomi `print("Hello, World!")`

Mari bedah bagian-bagiannya:

- **`print`** — nama fungsi. Python sudah mengenal kata ini secara bawaan.
- **`(`** dan **`)`** — tanda kurung wajib saat memanggil fungsi.
- **`"Hello, World!"`** — ini adalah **string** (teks). Diapit tanda kutip ganda.

:::note
Di Python, tanda kutip tunggal `'` dan ganda `"` bisa digunakan bergantian untuk string. `print('Hello')` dan `print("Hello")` menghasilkan hal yang sama. Pilih salah satu dan konsisten!
:::

## print() dengan Banyak Nilai

Kamu bisa mengirim beberapa nilai ke `print()`, dipisahkan koma:

```python
print("Nama:", "Budi")
print("Umur:", 17)
print("Nilai:", 85.5)
```

Output:
```
Nama: Budi
Umur: 17
Nilai: 85.5
```

Python otomatis menambahkan spasi di antara nilai-nilai tersebut.

## Escape Character

Escape character adalah karakter khusus yang diawali backslash `\`:

```python
print("Baris pertama\nBaris kedua")
print("Tab\tdi sini")
print("Dia berkata \"Halo!\"")
```

Output:
```
Baris pertama
Baris kedua
Tab	di sini
Dia berkata "Halo!"
```

| Escape | Arti |
|--------|------|
| `\n` | Baris baru |
| `\t` | Tab |
| `\"` | Tanda kutip ganda |
| `\'` | Tanda kutip tunggal |
| `\\` | Backslash |

## print() dengan `sep` dan `end`

`print()` punya parameter opsional:

```python
# sep: pemisah antar nilai (default: spasi)
print("apel", "mangga", "jeruk", sep=", ")

# end: karakter di akhir (default: newline \n)
print("Ini ", end="")
print("satu baris")
```

Output:
```
apel, mangga, jeruk
Ini satu baris
```

## Kesalahan Umum

**1. Lupa tanda kurung:**
```python
print "Hello"  # ERROR di Python 3! (ini sintaks Python 2)
```

**2. Lupa tanda kutip:**
```python
print(Hello)  # ERROR: Python mengira Hello adalah variabel
```

**3. Kutip tidak matching:**
```python
print("Hello')  # ERROR: buka dengan " tapi tutup dengan '
```

:::tip
Kalau menemui error `SyntaxError`, periksa tanda kurung dan tanda kutipmu — biasanya di situlah masalahnya.
:::

| Banyak nilai | `print("a", "b", "c")` |

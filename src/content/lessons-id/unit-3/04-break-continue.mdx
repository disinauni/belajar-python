# Break & Continue

## `break` — Keluar dari Loop

`break` menghentikan loop sepenuhnya dan langsung ke kode setelah loop.

```python
# Cari angka pertama yang habis dibagi 7
for i in range(1, 100):
    if i % 7 == 0:
        print(f"Angka pertama yang habis dibagi 7: {i}")
        break  # stop! tidak perlu cari lagi

# Output: Angka pertama yang habis dibagi 7: 7
```

## `continue` — Lewati Iterasi Ini

`continue` melewati sisa kode dalam iterasi saat ini dan lanjut ke iterasi berikutnya.

```python
# Print angka 1-10 kecuali yang habis dibagi 3
for i in range(1, 11):
    if i % 3 == 0:
        continue  # lewati, jangan print
    print(i, end=" ")

# Output: 1 2 4 5 7 8 10
```

## Contoh Nyata

```python
# Validasi input dengan break
while True:
    nilai = float(input("Masukkan nilai (0-100): "))
    if 0 <= nilai <= 100:
        break
    print("Nilai tidak valid!")

print(f"Nilai diterima: {nilai}")
```

```python
# Filter data positif dengan continue
data = [5, -3, 8, -1, 0, 7, -2, 4]
print("Angka positif:")
for angka in data:
    if angka <= 0:
        continue
    print(angka, end=" ")
# Output: 5 8 7 4
```

## Break vs Continue

| | break | continue |
|--|-------|----------|
| Efek | Keluar dari loop | Lewati iterasi ini |
| Loop berlanjut? | Tidak | Ya |
| Kapan digunakan | Sudah dapat yang dicari | Skip kondisi tertentu |

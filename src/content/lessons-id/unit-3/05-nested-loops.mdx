# Nested Loops

Nested loop adalah loop di dalam loop. Untuk setiap iterasi loop luar, loop dalam berjalan **penuh satu putaran**.

## Contoh Dasar

```python
for i in range(1, 4):         # loop luar: 1, 2, 3
    for j in range(1, 4):     # loop dalam: 1, 2, 3
        print(f"({i},{j})", end=" ")
    print()  # baris baru setelah loop dalam selesai
```

Output:
```
(1,1) (1,2) (1,3)
(2,1) (2,2) (2,3)
(3,1) (3,2) (3,3)
```

## Tabel Perkalian

```python
print("Tabel Perkalian 1-5")
print("   ", end="")
for j in range(1, 6):
    print(f"{j:4}", end="")
print()
print("─" * 24)

for i in range(1, 6):
    print(f"{i} |", end="")
    for j in range(1, 6):
        print(f"{i*j:4}", end="")
    print()
```

## Pola Bintang

```python
# Segitiga bintang
baris = 5
for i in range(1, baris + 1):
    for j in range(i):
        print("*", end="")
    print()
```

Output:
```
*
**
***
****
*****
```

## Performa

Hati-hati dengan nested loop yang dalam — kompleksitasnya bertumbuh cepat:
- 1 loop: O(n)
- 2 nested loops: O(n²)
- 3 nested loops: O(n³)

Untuk data besar, cari cara yang lebih efisien.

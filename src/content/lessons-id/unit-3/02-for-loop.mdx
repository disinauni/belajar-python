# For Loop

`for` loop dirancang untuk **mengiterasi** (melewati satu per satu) item dalam sebuah koleksi.

## Sintaks For Loop

```python
for item in koleksi:
    # kode untuk setiap item
```

## Iterasi String

```python
kata = "Python"

for huruf in kata:
    print(huruf)
```

Output:
```
P
y
t
h
o
n
```

## Iterasi List

```python
buah = ["apel", "mangga", "jeruk", "pisang"]

for b in buah:
    print(f"Saya suka {b}")
```

## Iterasi dengan range()

```python
# range(5) → 0, 1, 2, 3, 4
for i in range(5):
    print(i)

# range(1, 6) → 1, 2, 3, 4, 5
for i in range(1, 6):
    print(i)

# range(0, 10, 2) → 0, 2, 4, 6, 8
for i in range(0, 10, 2):
    print(i)
```

## Contoh Program

```python
# Tabel perkalian
angka = int(input("Tabel perkalian angka berapa? "))
print(f"\nTabel perkalian {angka}:")
print("-" * 20)

for i in range(1, 11):
    hasil = angka * i
    print(f"{angka} × {i:2d} = {hasil:3d}")
```

## For vs While

| Situasi | Pilihan |
|---------|---------|
| Jumlah iterasi diketahui | `for` |
| Iterasi koleksi (list, string) | `for` |
| Kondisi stop tidak tentu | `while` |
| Validasi input | `while` |

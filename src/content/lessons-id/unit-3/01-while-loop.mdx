# While Loop

Loop (perulangan) adalah salah satu konsep terpenting dalam programming. Dengan loop, kamu bisa menjalankan kode yang sama berkali-kali tanpa menulis ulang.

## Sintaks While Loop

```python
while kondisi:
    # kode yang diulang selama kondisi True
```

## Contoh Sederhana

```python
hitung = 1

while hitung <= 5:
    print(f"Hitungan ke-{hitung}")
    hitung += 1  # PENTING: selalu ubah kondisi agar tidak infinite!

print("Selesai!")
```

Output:
```
Hitungan ke-1
Hitungan ke-2
Hitungan ke-3
Hitungan ke-4
Hitungan ke-5
Selesai!
```

## Infinite Loop — Hindari!

```python
# JANGAN INI — program tidak akan berhenti!
# while True:
#     print("Halo")  # tidak ada yang menghentikannya!

# Yang benar — pastikan ada kondisi yang akan membuat while False
i = 0
while i < 5:
    print(i)
    i += 1  # tanpa ini, i tidak pernah berubah → infinite loop
```

## While untuk Validasi Input

Ini adalah penggunaan paling umum while loop:

```python
while True:
    umur = int(input("Masukkan umur (0-150): "))
    if 0 <= umur <= 150:
        break  # keluar dari loop jika input valid
    print("Umur tidak valid! Coba lagi.")

print(f"Umur kamu: {umur} tahun")
```

## Contoh: Hitung Mundur

```python
import time

print("Hitung mundur peluncuran roket!")
n = 10

while n > 0:
    print(f"{n}...")
    n -= 1

print("🚀 LIFTOFF!")
```

## Contoh: Akumulasi

```python
# Hitung total belanja
total = 0
print("Masukkan harga barang (0 untuk selesai):")

while True:
    harga = float(input("Harga: "))
    if harga == 0:
        break
    total += harga
    print(f"Subtotal: Rp {total:,.0f}")

print(f"\nTotal belanja: Rp {total:,.0f}")
```

## Ringkasan

| Konsep | Keterangan |
|--------|------------|
| `while kondisi:` | Ulangi selama kondisi True |
| Perbarui kondisi | Wajib agar tidak infinite loop |
| `while True:` | Loop tak terbatas, perlu `break` |
| `break` | Keluar dari loop |

# Project: Pola Bintang

Membuat pola bintang adalah latihan klasik untuk memahami nested loop. Mari buat beberapa pola!

## Pola 1: Segitiga Kanan

```python
n = 5
for i in range(1, n + 1):
    print("*" * i)
```
```
*
**
***
****
*****
```

## Pola 2: Segitiga Terbalik

```python
n = 5
for i in range(n, 0, -1):
    print("*" * i)
```

## Pola 3: Piramida

```python
n = 5
for i in range(1, n + 1):
    spasi = " " * (n - i)
    bintang = "*" * (2 * i - 1)
    print(spasi + bintang)
```
```
    *
   ***
  *****
 *******
*********
```

## Pola 4: Berlian

```python
n = 5
# Bagian atas
for i in range(1, n + 1):
    print(" " * (n - i) + "*" * (2 * i - 1))
# Bagian bawah
for i in range(n - 1, 0, -1):
    print(" " * (n - i) + "*" * (2 * i - 1))
```

## Pola 5: Generator Interaktif

```python
print("=== Generator Pola Bintang ===\n")
print("Pilih pola:")
print("1. Segitiga kanan")
print("2. Piramida")
print("3. Berlian")
print("4. Kotak berlubang")

pilihan = input("\nPilihan: ")
ukuran = int(input("Ukuran: "))

print()
if pilihan == "1":
    for i in range(1, ukuran + 1):
        print("*" * i)

elif pilihan == "2":
    for i in range(1, ukuran + 1):
        print(" " * (ukuran - i) + "*" * (2 * i - 1))

elif pilihan == "3":
    for i in range(1, ukuran + 1):
        print(" " * (ukuran - i) + "*" * (2 * i - 1))
    for i in range(ukuran - 1, 0, -1):
        print(" " * (ukuran - i) + "*" * (2 * i - 1))

elif pilihan == "4":
    for i in range(ukuran):
        if i == 0 or i == ukuran - 1:
            print("*" * ukuran)
        else:
            print("*" + " " * (ukuran - 2) + "*")

print("\nSelesai! Coba ubah ukurannya.")
```

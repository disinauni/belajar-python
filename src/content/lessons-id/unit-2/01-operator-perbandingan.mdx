# Operator Perbandingan

Operator perbandingan membandingkan dua nilai dan menghasilkan `True` atau `False`.

## Daftar Operator Perbandingan

```python
a = 10
b = 5

print(a == b)   # False (sama dengan)
print(a != b)   # True  (tidak sama dengan)
print(a > b)    # True  (lebih besar)
print(a < b)    # False (lebih kecil)
print(a >= b)   # True  (lebih besar atau sama)
print(a <= b)   # False (lebih kecil atau sama)
```

## Membandingkan String

```python
nama1 = "Budi"
nama2 = "Siti"

print(nama1 == nama2)   # False
print(nama1 != nama2)   # True
print("abc" < "abd")    # True (perbandingan alfabetis)
print("A" < "a")        # True (huruf kapital lebih kecil)
```

## Membandingkan Tipe Berbeda

```python
print(1 == 1.0)   # True (Python membandingkan nilainya)
print(1 == "1")   # False (int vs str — berbeda tipe!)
print(0 == False) # True (0 dan False keduanya "falsy")
print(1 == True)  # True
```

:::warning
Jangan gunakan `==` untuk membandingkan dengan `None`. Gunakan `is` atau `is not`:
```python
x = None
print(x is None)      # True (benar)
print(x == None)      # True (berfungsi tapi kurang tepat)
print(x is not None)  # False
```
:::

## Chained Comparison

Python punya fitur unik — bisa merantai perbandingan:

```python
nilai = 75

# Di bahasa lain harus tulis: nilai >= 60 and nilai <= 100
# Di Python bisa lebih ringkas:
print(60 <= nilai <= 100)    # True
print(0 < nilai < 50)        # False

umur = 17
print(13 <= umur <= 17)      # True (remaja)
```

## Ringkasan

| Operator | Arti | Contoh | Hasil |
|----------|------|--------|-------|
| `==` | Sama dengan | `5 == 5` | `True` |
| `!=` | Tidak sama | `5 != 3` | `True` |
| `>` | Lebih besar | `5 > 3` | `True` |
| `<` | Lebih kecil | `5 < 3` | `False` |
| `>=` | Lebih besar/sama | `5 >= 5` | `True` |
| `<=` | Lebih kecil/sama | `5 <= 3` | `False` |

Di pelajaran berikutnya: **If-Elif-Else** — membuat keputusan berdasarkan kondisi!

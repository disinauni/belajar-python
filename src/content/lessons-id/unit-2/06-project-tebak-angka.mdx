# Project: Game Tebak Angka

Selamat! Kamu sudah menguasai semua konsep percabangan di Unit 2. Sekarang waktunya membuat **game tebak angka** yang menyenangkan!

## Modul Random

Python punya modul `random` untuk menghasilkan angka acak:

```python
import random

angka = random.randint(1, 100)  # angka acak antara 1-100
print(angka)  # berbeda setiap kali dijalankan
```

## Versi 1: Tebak Sekali

```python
import random

print("=== GAME TEBAK ANGKA ===")
print("Aku sedang memikirkan angka 1-100...")

angka_rahasia = random.randint(1, 100)
tebakan = int(input("\nTebakanmu: "))

if tebakan == angka_rahasia:
    print("🎉 BENAR! Luar biasa!")
elif tebakan > angka_rahasia:
    print(f"Terlalu besar! Jawabannya adalah {angka_rahasia}")
else:
    print(f"Terlalu kecil! Jawabannya adalah {angka_rahasia}")
```

## Versi 2: Dengan Petunjuk dan Skor

```python
import random

print("╔══════════════════════════╗")
print("║    GAME TEBAK ANGKA      ║")
print("╚══════════════════════════╝")

nama = input("Namamu: ")
print(f"\nHalo {nama}! Aku sedang memikirkan angka 1-100.")
print("Kamu punya 3 kesempatan!")

angka_rahasia = random.randint(1, 100)
menang = False
skor = 100

for percobaan in range(1, 4):
    print(f"\n--- Percobaan {percobaan}/3 ---")
    tebakan = int(input("Tebakanmu: "))
    skor -= 20  # kurangi skor setiap percobaan

    if tebakan == angka_rahasia:
        menang = True
        break
    elif abs(tebakan - angka_rahasia) <= 10:
        print("🔥 Sangat dekat!")
    elif tebakan > angka_rahasia:
        print("⬇️  Terlalu besar")
    else:
        print("⬆️  Terlalu kecil")

print()
if menang:
    skor = max(skor + 60, 10)  # bonus skor
    print(f"🎉 BENAR! Jawabannya memang {angka_rahasia}!")
    print(f"Skor kamu: {skor}/100")

    if skor >= 80:
        print("⭐⭐⭐ Luar biasa!")
    elif skor >= 60:
        print("⭐⭐ Bagus!")
    else:
        print("⭐ Cukup bagus, latihan terus!")
else:
    print(f"😅 Sayang sekali! Angkanya adalah {angka_rahasia}")
    print("Coba lagi ya!")
```

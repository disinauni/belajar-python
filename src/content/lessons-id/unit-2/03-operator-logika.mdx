# Operator Logika

Terkadang kamu perlu mengecek lebih dari satu kondisi sekaligus. Operator logika memungkinkan kamu menggabungkan kondisi-kondisi tersebut.

## Tiga Operator Logika

### `and` — Keduanya harus True

```python
umur = 17
punya_ktp = True

if umur >= 17 and punya_ktp:
    print("Boleh mendaftar")
else:
    print("Tidak memenuhi syarat")
```

| A | B | A and B |
|---|---|---------|
| True | True | **True** |
| True | False | False |
| False | True | False |
| False | False | False |

### `or` — Salah satu cukup True

```python
hari = "Sabtu"

if hari == "Sabtu" or hari == "Minggu":
    print("Hari libur!")
else:
    print("Hari kerja")
```

### `not` — Membalik nilai boolean

```python
sudah_login = False

if not sudah_login:
    print("Silakan login terlebih dahulu")
```

## Menggabungkan Operator

```python
nilai = 85
absen = 3

if nilai >= 75 and absen <= 5:
    print("Lulus!")
else:
    print("Tidak lulus")
```

## Contoh Program

```python
print("=== Cek Kelayakan Beasiswa ===")

nilai_rata = float(input("Nilai rata-rata: "))
penghasilan = int(input("Penghasilan ortu (juta/bulan): "))

layak = (nilai_rata >= 80 and penghasilan <= 3) or nilai_rata >= 90

if layak:
    print("Selamat! Kamu layak mendapat beasiswa.")
else:
    print("Belum memenuhi syarat beasiswa.")
```

## Ringkasan

| Operator | True jika |
|----------|-----------|
| `and` | Semua kondisi True |
| `or` | Minimal satu True |
| `not` | Kondisi False |
